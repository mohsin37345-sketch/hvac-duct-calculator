## Manual vs Automatic Duct Sizing

HVAC professionals can size ducts using hand calculations with formulas and charts, or they can use automated tools like calculators and software. Both approaches produce valid results, but they differ in speed, accuracy, and convenience.

## Manual Duct Sizing

### What It Involves
Manual duct sizing uses the ASHRAE friction chart, engineering formulas, and a physical ductulator or lookup tables to determine duct sizes.

The process:
1. Calculate room by room CFM requirements
2. Determine available static pressure
3. Calculate TEL for each run (by hand)
4. Look up duct size on friction chart for given CFM and friction rate
5. Verify velocity is acceptable
6. Calculate total pressure drop
7. Document all calculations

### Advantages
- **Deep understanding**: Forces the designer to understand every variable
- **No technology dependence**: Works with paper and pencil
- **Full control**: Every assumption is explicit and documented
- **Professional credibility**: Demonstrates engineering competence

### Disadvantages
- **Time consuming**: A complete system can take hours to calculate by hand
- **Error prone**: Math mistakes, chart reading errors, and missed fittings
- **Tedious iterations**: Changing one parameter requires recalculating everything
- **Limited "what if" analysis**: Hard to compare multiple design options quickly

## Automatic Duct Sizing

### What It Involves
Using online calculators, mobile apps, or professional HVAC design software to compute duct sizes from input parameters.

Tools range from:
- **Simple calculators** (like our [HVAC Duct Calculator](/)) for individual duct runs
- **Design software** (Wrightsoft, Elite RHVAC) for complete system designs

### Advantages
- **Speed**: Calculate any duct size in seconds
- **Accuracy**: No math errors, no chart reading mistakes
- **Easy iterations**: Change inputs and instantly see new results
- **Automatic conversions**: Round to rectangular, metal to flex adjustments
- **TEL automation**: Some tools calculate fitting equivalent lengths automatically
- **Documentation**: Results can be saved and shared

### Disadvantages
- **Black box risk**: Users may not understand the underlying calculations
- **Technology dependence**: Requires a device with internet or software
- **Garbage in, garbage out**: Wrong inputs produce wrong outputs regardless of tool quality
- **Over reliance**: May skip verification steps that manual calculation would catch

## Accuracy Comparison

Both methods produce identical results when used correctly because they apply the same formulas. The accuracy difference comes from human factors:

| Factor | Manual | Automatic |
|---|---|---|
| Formula application | Risk of math error | Error free |
| Input accuracy | Same | Same |
| Chart reading | ±5% reading error | Exact computation |
| Fitting counting | Easy to miss | Still requires manual count |
| Overall accuracy | 90% to 95% | 99%+ |

## When to Use Each Method

### Use Manual Methods When:
- Learning duct sizing fundamentals
- No internet or devices available
- Quick field verification with a ductulator
- Building codes require showing hand calculations

### Use Automatic Methods When:
- Designing a complete duct system
- Need fast results for multiple scenarios
- Working with flex duct (corrections are complex by hand)
- Client expects professional documentation
- Comparing design alternatives

### Best Practice: Combine Both
Use automatic tools for speed and accuracy, but understand the manual process so you can verify results, catch errors, and explain calculations to clients.
